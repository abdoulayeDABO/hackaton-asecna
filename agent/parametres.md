# Paramètres de l’agent

Les paramètres ci-dessous doivent être relevés dans l’environnement UiPath réellement déployé. Ils ne sont pas inventés dans ce dépôt.

| Paramètre | Valeur |
|---|---|
| Modèle | À COMPLÉTER |
| Température | À COMPLÉTER |
| Outils | À COMPLÉTER |
| Nom de l’agent | À COMPLÉTER |
| Environnement UiPath | À COMPLÉTER |
| Date de déploiement | À COMPLÉTER |
| Version du prompt | À COMPLÉTER |

## Remarques

- Pour l’évaluation, la température recommandée est `0`. La valeur réellement configurée reste À COMPLÉTER.
- La liste des outils réellement attachés à l’agent doit être vérifiée dans UiPath. Les outils documentés dans ce dépôt sont :
  - `ATM_API_Etat`
  - `ATM_API_Anomalies`
  - `ATM_API_Aerodromes`
  - `ATM_API_EspacesAeriens`
  - `ATM_API_Recherche`
  - `ATM_API_Changements`
- Le serveur MCP associé est `atm-swim-v1`.
- Ne jamais placer de secret, de mot de passe, de jeton ou de clé dans ce fichier.
